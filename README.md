ZIP में प्रकाशित DayBook का पूरा React + Tailwind source code और तैयार बिल्ड है। इसे extract करके VS Code में खोलें।
फ़ाइल	क्या मिलेगा
src/app.jsx	DayBook UI, सेल एडिटिंग और दैनिक टोटल
src/entries.js	ब्राउज़र में एंट्री पढ़ने और सेव करने का कोड
dist/style.css	रजिस्टर का लेआउट और डिज़ाइन
dist/index.html	तैयार ऐप का शुरुआती पेज


प्रोजेक्ट फ़ोल्डर में ये कमांड चलाएँ:
npm ci
npm run build
npx serve dist

फिर टर्मिनल में दिखा लोकल URL खोलें।
